# ZCode 的 pptx-renderer 能否纳入 Artifact SDK？

结论：可作为可分发的轻量 **PPTX 静态渲染后端**；它不是 Office 编辑 SDK，渲染成功也不保证内容完整。SDK 需要补齐源文件能力诊断、加载稳定判定与证据关联，复杂内容按实际能力另选后端。[授权](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/LICENSE#L66-L110)、[公开 API](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/index.ts#L1-L94)、[静默降级](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/ImageRenderer.ts#L862-L922)。

## 接入必须处理的实际缺口

- `onNodeError` 只覆盖部分异常：未知节点可空 div、未知 graphicFrame 可 undefined、template parse/master/layout 异常可静默；group 子节点虽画错误框却不一定回调。必须检查源 OOXML 与声明支持范围，报告缺失/降级，不能靠零回调推导完整。[分派/模板](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/SlideRenderer.ts#L71-L181)、[master/layout](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/SlideRenderer.ts#L296-L351)、[group](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/GroupRenderer.ts#L315-L338)。
- `SlideHandle.ready` 是已注册 task 的 `allSettled`，不因 rejection 失败；普通 img 解码和字体稳定不完整包含其中；autofit 有延后的 animation-frame/font 回调。应先挂载、等待 handle、显式字体/图片解码、布局稳定并设 deadline，记录失败；`sliderendered` 事件本身也不等待 ready。[ready](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/SlideRenderer.ts#L354-L389)、[img](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/ImageRenderer.ts#L200-L228)、[autofit](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/ShapeRenderer.ts#L2871-L2883)、[viewer](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/core/Viewer.ts#L973-L987)。
- ZIP 默认无 limits；应用应显式传 `RECOMMENDED_ZIP_LIMITS`（或更严）。windowed/lazy 是交互优化，逐页验收必须明确 materialize/render 全部目标页，不能拿首屏完成代表全文件。[ZIP/分页](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/README.md#L363-L382)、[导出模式](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/README.md#L626-L654)。
- 外链仅做协议过滤；HTTP(S) 图片可实际加载，媒体也可加载外部 URL，链接点击可导航。应使用本地静态资源、受控浏览器网络策略及导航回调，并将被阻资源记作缺失；PDF.js module/worker URL 也应固定本地资源。[URL filter](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/utils/urlSafety.ts#L5-L33)、[external image](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/ImageRenderer.ts#L43-L48)、[PDF assets](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/utils/pdfRenderer.ts#L17-L82)。
- README 的“shadow/reflection/glow 不支持”与 1.2.4 已有部分源码实现冲突；以具体对象/效果的代码与测试为准，不宣称完全支持或完全不支持。[README](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/README.md#L690-L692)、[图片效果](https://github.com/aiden0z/pptx-renderer/blob/b28ab6326ba058138b662714be15335e5ca1f1a8/src/renderer/ImageRenderer.ts#L498-L633)。
- 公开最新 1.3.0（2026-09-14）改善 CJK、表格、图表并新增有限 OMML/static 3D/font；依赖多 `mtx-decompressor`，90 文件/3,534,629 bytes，仍 browser-only、无动画播放/转场/完整向量或 Office 写回。应单独做版本验收，不把 ZCode 的 1.2.4 实测算作 1.3.0 证据。[npm](https://registry.npmjs.org/@aiden0z/pptx-renderer/1.3.0)、[changelog](https://github.com/aiden0z/pptx-renderer/blob/0cf5c194b4db2cf9f2531b6a7e24a61338caabf1/CHANGELOG.md#L9-L27)、[边界](https://github.com/aiden0z/pptx-renderer/blob/0cf5c194b4db2cf9f2531b6a7e24a61338caabf1/README.md#L739-L753)。
