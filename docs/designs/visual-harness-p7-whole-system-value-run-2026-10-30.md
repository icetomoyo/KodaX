## 为什么停止，哪些失败保留

DeepSeek r3 首请求只有起始 usage 和心跳，原 AbortSignal 没有及时结束响应体。Host 终止了该路线，未自动重试；传输适配器随后补上 headers、逐次读取及账户观测的显式超时竞争。原失败及缺失 usage 保留。

r4 将剩余额度用于一次最终 Kimi panel，未扩大原联合预算；明确不再调题或追加样本追求胜出。首格前台交付后的后台请求超时，按冻结策略停止该路线，所以其余五格未执行。没有解锁旧账本或绕过停止条件继续请求。

以下都属于实验限制或 provider 故障，不能混写为产品能力失败：Windows cmd 与模型默认 POSIX 命令不匹配、输出截断、暖场次数不足、过早暴露最终问题、单格 token 截断、响应体超时。反过来，实际漏掉图例且错误认可图例，则是真实语义错误，不能借执行限制抹掉。
