## 执行修复和失败保留

评估器保留生产更小的输出上限，覆盖响应头/响应体超时；已知可选 stall/学习复盘在完整 usage 入账后失败时，由生产失败路径处理，不再取消主任务。后台失败单独记账，队列排空不冒充后台成功；真实预算、账本及输出超限仍硬停止。

r5d 历史再次触及600k限制后，按用户“不用限制过度严格预算”的要求扩大剩余 H/V 的 Host token额度，未改题；原始中断不删除。r5e完成两个视频格，r5f完成同会话历史续段。没有自动重试、增加题目、为了胜出追加样本或修改生产融合代码。

从 r2 到 r5f 的本套整任务实验累计 **147 次生成尝试、143 次有最终 usage、已知3,633,650 token**。四次旧请求没有完整 usage，真实实验总量仍未知；其中已知输入及输出上限预留合计44,889 token，另有用户批准的50,000规划预留，二者都不是实际用量，后者也不是已证明上界。最终六格的2,069,676 token是此累计的已选子集，不能再加一次；更早的方法位置实验不在这个累计口径内。
