## 最小修订

1. L 新增与视频解码器同性质的中性 `render-report.py`：可按页、分辨率渲染并创建输出目录，通用像素裁图不预选问题区域。两边输入完全相同，原 PDF 字节、CSV、缺陷真值不变；正常自写脚本仍可用。
2. 三类任务均明确宿主 shell 是 Windows cmd，建议单命令或写本地脚本，避免 POSIX 分号/heredoc和多行 `-c`。只说明真实运行环境，不提示缺陷位置或要求调用新增视觉工具。
